A c++ Snake game made using raylib library focusing on retro theme .Features:

  1) Random food spawn
  2) Custom sound for food
  3) Snake grows as increase in food consumption
  4) Game over it you hit wall
  5) Game over when snake head touches it's tail
  6) Custom sound on game over
  7) Shows  your score on bottom left while playing
  8) Shows game over screen when the game is over
  9) Show your message and total score in the previous game in game over window
  10) Triggers a reset game function if space key is pressed in case of game over
  11) Exit game when ESC key is pressed or window is closed
